What I work on

AI-assisted kernel engineering

Code models write the first version of a compute kernel. My work is the methodology that follows: holding the output to a benchmark instead of an impression, and finding where the generated version actually loses to a tuned library.

Autotuning and measurement

Searching tiling, blocking and threading parameters with Bayesian optimisation, gradient descent and annealing, on a timing harness built to be reproducible.

Applied machine learning

Transformer baselines, ensembling and per-class diagnostics, with the same bias toward evaluation I bring to performance work.

Selected work

AI-Driven BLAS Library

A multithreaded BLAS implementation built to rival OpenBLAS, where an AI assistant writes the kernels and I build the optimisation methodology around them: AVX2 microkernels with FMA, cache tiling, autotuned parameter search, and coverage across levels 1 to 3.
