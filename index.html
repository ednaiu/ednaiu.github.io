I work on the measurement side of high-performance computing: benchmarking, autotuning and kernel optimisation. Increasingly a code model writes the first version of the kernel, which makes the interesting question no longer how to write it, but how to establish whether it is actually faster than the library it means to replace.

What I work on

03

AI-assisted kernel engineering

Using code models to generate and refine compute kernels, then holding the output to a benchmark rather than to an impression. The methodology around the generation is the work.

Autotuning and measurement

Searching tiling, blocking and threading parameters with Bayesian optimisation, gradient descent and simulated annealing, and building the reproducible timing harness that decides which point in that space wins.

Applied machine learning and evaluation

Transformer baselines, ensembling and per-class diagnostics on classification tasks, with the same bias toward evaluation that I bring to performance work.

Selected work

03

AI-Driven BLAS Library

Research project (TER) · Paris-Saclay
Supervised by Oguz Kaya · graded 19/20

A multithreaded BLAS implementation built to rival OpenBLAS, in which the kernels are produced with an AI coding assistant and my contribution is the optimisation methodology around them: AVX2 microkernels with FMA, cache tiling, autotuned parameter search, and coverage across BLAS levels 1 to 3, each measured against the reference implementation.

C AVX2 + FMA OpenMP 20-core Intel reference: OpenBLAS

Cloud GPU Compiler

VS Code extension · published
Visual Studio Marketplace

Compiles and runs CUDA on remote GPUs through the Compiler Explorer API, so a developer on a machine with no NVIDIA card — a Mac, for instance — can still build and execute .cu files and full CMake projects with no local toolchain, and read the output in the editor.

TypeScript CUDA nvcc via Compiler Explorer CMake projects
Marketplace

Stance Detection in Conversations

Applied NLP
RumourEval framing

Four-way stance classification — support, deny, query, comment — over source-and-reply conversation pairs. Five approaches compared, from a TF-IDF baseline through sentence embeddings and cross-encoder scoring to a confidence-based ensemble, packaged for inference and reported with macro F1 and per-class diagnostics.
